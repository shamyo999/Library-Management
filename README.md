# 📚 Library Management System (Java)

## 🚀 Features
- Add books
- Borrow books (limit: 3 per user)
- Return books
- View available books
- View user status

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Encapsulation
- Classes & Objects
- HashMap & ArrayList

## ▶️ How to Run
1. Compile all Java files
2. Run `Main.java`
